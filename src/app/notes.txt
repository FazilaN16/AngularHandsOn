1. angular.json - Contains the Angular project configuration such as build, serve, assets, and styles.

2. tsconfig.json - Main TypeScript configuration file used by the project.

3. tsconfig.app.json - TypeScript configuration specifically for the Angular application source code.

4. package.json - Stores project information, dependencies, and npm scripts.

5. src/main.ts - Entry point of the Angular application that bootstraps the root component.

6. src/app/app.config.ts - Contains application-wide configuration for the standalone Angular application.

7. src/app/app.ts - Defines the root component and its metadata.

8. src/index.html - Main HTML page that hosts the Angular application.
9. Budgets (angular.json)
   - maximumWarning: Shows a warning if the application bundle size exceeds the specified limit.
   - maximumError: Stops the build if the application bundle size exceeds the specified limit.
